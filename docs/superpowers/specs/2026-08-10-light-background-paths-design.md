# Token Dashboard · 浅色 Background Paths 视觉优化

## 目标

在不改变 Python API、数据采集、图表数据和刷新逻辑的前提下，将现有启动页及仪表盘整理为更贴近 v0 `Background Paths` 模板的浅色体验：白色空间、石板灰路径、克制的玻璃质感与柔和进入过渡。

## 范围

- 保留全屏启动页、中文产品名称与“进入看板”动作。
- 调整路径 SVG 的层级、透明度、速度和动画节奏；路径是唯一的显著装饰。
- 统一浅色 token：白色背景、蓝灰文字、青绿色强调、低对比边框与阴影。
- 优化启动页到仪表盘的淡出/淡入过渡，保持已有数据卡片、图表和表格结构。
- 补齐键盘焦点、移动端间距与 `prefers-reduced-motion` 下的静态回退。

## 不在范围内

- 不修改 `server.py`、`collectors.py`、数据库结构或 API 返回格式。
- 不替换 ECharts 或增添新数据指标。
- 不复制参考站的文案、源码或品牌资产。

## 视觉系统

| 用途 | 色值 |
| --- | --- |
| 页面白 | `#FFFFFF` |
| 冷雾底 | `#F8FAFC` |
| 石板文字 | `#0F172A` |
| 次级文字 | `#64748B` |
| 路径灰蓝 | `#475569` / `#CBD5E1` |
| 状态强调 | `#0D9488` |

标题采用深色到石板灰的细微渐变；数据数字采用等宽字体。启动页使用较清晰的路径，仪表盘中路径退为低透明度背景，确保图表和表格优先级最高。

## 验收标准

1. 页面首次打开仍展示浅色启动页，点击按钮后仪表盘正常出现。
2. 背景路径连续流动且不出现闪烁、小点或遮挡交互内容。
3. `/api/data` 仍可正常填充全部统计、图表和最近记录。
4. 视口宽度 560px 以下没有横向页面溢出，图表可正常缩放。
5. 减少动态设置下关闭路径及进入动画，但页面功能完整可用。
